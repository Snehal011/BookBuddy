# 📚 BookBuddy – Social Book Club App

BookBuddy is a mobile application that brings book lovers together through a digital reading community. Users can discover books, track their reading progress, join virtual book clubs, and interact with other readers through real-time discussions.

The application is built using **React Native with Expo** and uses **Firebase** for backend services and real-time functionality.

---

## ✨ Features

* 📖 **Reading Progress Tracking**
  Track your reading progress and manage your current books.

* 👥 **Virtual Book Clubs**
  Join book clubs and participate in group reading and discussions.

* 💬 **Real-Time Chatrooms**
  Communicate with other club members through real-time messaging.

* 🔎 **Book Discovery & Recommendations**
  Explore books and discover new reading recommendations.

* 🔐 **User Authentication**
  Login and signup functionality for managing user accounts.

* 📱 **Mobile-Friendly UI**
  Clean and intuitive interface designed for mobile users.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Expo CLI / Expo
* Expo Go mobile application
* Git

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project

```bash
cd BookBuddy
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Expo Development Server

```bash
npx expo start
```

You can then scan the QR code using **Expo Go** to run the application on a mobile device.

---

## 🔥 Firebase Configuration

BookBuddy uses Firebase for authentication, data management, and real-time communication.

To configure Firebase:

1. Create a project in Firebase Console.
2. Enable the required Firebase services.
3. Register the application with Firebase.
4. Add the Firebase configuration to the project.
5. Configure authentication and database services as required.

> **Note:** Do not commit Firebase credentials or sensitive configuration files to the public repository.
